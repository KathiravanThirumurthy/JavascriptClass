###
What is JavaScript?
JavaScript is a programming language used to make web pages interactive and dynamic.
HTML       → Structure
CSS        → Appearance
JavaScript → Behaviou
### Why Javascript ?
Without JavaScript, most webpages would be largely static.
Respond to user actions
Validate forms
Change webpage content
Show/hide elements
Create interactive menus
Build calculators
Create games
Communicate with servers
Build modern web applications
### Where does JavaScript run?
For beginner web development, JavaScript commonly runs inside the web browser.
Examples:
Chrome
Edge
Firefox
Safari
The browser contains a JavaScript engine that executes the code.
