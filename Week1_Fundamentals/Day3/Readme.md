###
What is a Variable?
A variable is a named container used to store data.
let studentName = "Arun";
let age = 20;
Use let when the value may change.
Use const when the value should not be reassigned.

const collegeName = "ABC College";

const collegeName = "ABC College"; // old JAvascript
let and const  //  modern javascript
