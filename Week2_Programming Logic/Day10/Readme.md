Mini Project — Student Result Management

Students create a program containing:

let students = [
    {
        name: "Arun",
        marks: [80, 75, 90]
    },
    {
        name: "Priya",
        marks: [90, 85, 95]
    },
    {
        name: "Rahul",
        marks: [65, 70, 72]
    }
];

Then create functions such as:

calculateTotal()
calculateAverage()
calculateGrade()
displayStudentResult()

Use loops and conditions to process the data.

Expected Output
Student: Arun

Maths:    80
Science:  75
English:  90

Total:    245
Average:  81.67
Grade:    B
Status:   Pass

### Product Inventory System

Create an array containing at least 5 product objects.

Each product:

Product ID
Product Name
Category
Price
Stock

Students must implement:

Basic
Display all products
Display product names
Display prices
Intermediate
Find products below ₹500
Find products with stock = 0
Calculate total inventory value
Challenge

Create a function:

searchProduct(productName)

that searches the array and displays the matching product.

### Assessment

### Beginner
Check whether a number is positive or negative.
Find whether a number is even or odd.
Print numbers from 1 to 100.
Find the largest of three numbers.

### Intermediate
Calculate the average of an array.
Find the largest value in an array.
Search for a value in an array.
Count how many students passed.

### Challenge
Create an array of student objects and find:
Highest scorer
Lowest scorer
Average mark
Number of passed students
